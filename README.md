# PONet
This repository is about the work of PONet: A Progressive Hierarchical Network with Omni-Directional Complementary Exploration for Cross-Modal Aggregation in V-D-T Salient Object Detection.

Our code will be publicly released after the paper is accepted.

Datasets
====
The datasets utilized in this work can be accessed from Baidu Drive (extraction code:), including VDT-2048, NLPR, NJU2K, SIP, STERE, VT821, VT1000 and VT5000.

Saliency maps
====
We provide saliency maps of our PONet in Baidu Drive (extraction code:) on VDT-2048, NLPR, NJU2K, SIP, STERE, VT821, VT1000 and VT5000.
